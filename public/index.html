GOOD TO KNOW

A little clarity.

Small answers to common questions.

Is it really free?

Yes. Every feature here is free to use, with no account, subscription, or forced watermark. Add your own text watermark only if you choose.

Where do my photos go?

They stay in your browser. The tool doesn’t upload or store your photos on a server. Download any result you want to keep before closing or refreshing the page.

How do I crop or adjust a photo?

Choose Crop & size presets from the tool menu, then use Crop & frame to pick a shape, zoom in, and move the framing. Choose Light & color from the menu to change brightness or contrast, or switch to black & white. Quick size presets set the crop and output dimensions together. Check the preview, then use the tool’s action button to create your download. These edits apply to the single-photo tool.

Can I add my name or choose a background?

Choose Text watermark from the menu to add a name or brand, then choose its position, color, size, and opacity. Transparency background fills transparent pixels with a color; it does not remove an existing background. Each tool opens its own workspace for one photo at a time. You can also enter a download filename, and the tool adds the correct extension.

Can I make a small file bigger?

Yes. Choose “Exact file size” from the menu and enter the size you need, such as 50 KB. The tool saves a JPG at that size, adding non-image data if needed. This increases the file size without adding detail or improving quality. To change the photo’s dimensions instead, use Width and Height.

Will it always reach my target size?

Exact mode saves a JPG at your chosen size when the image can fit within that target. Very small targets may need smaller dimensions. Maximum mode only keeps the result under a limit, so a smaller file can stay smaller. We’ll clearly show when a target cannot be met. Here, 1 KB means 1,000 bytes. Other websites may change file size if they reprocess the image.

Can I use this for an application form?

Yes. Follow the form’s own format, dimension, and size requirements. This tool can resize and compress a photo; it doesn’t check official photo rules, remove backgrounds, or guarantee acceptance.
